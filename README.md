# 💳 クレカ請求 やりくりチェッカー

クレジットカードの請求額と給与の入金タイミングを突き合わせ、**「支払いに間に合うか」**を判定する静的Webアプリです。サーバー不要、データはブラウザ内（localStorage）にのみ保存されます。そのまま **GitHub Pages** で公開できます。

## 何ができる？

1. **口座残高・基準日**を入力（残高は自動で記憶し、次回復元）
2. **給与**を入力
   - 家庭教師（**末日入金**）… 入力金額は履歴に残り、あとからプルダウンで選べます
   - ハンバーグ屋バイト（変動するため記憶しません）
3. **クレカ請求額**を発行会社別に入力。各カードで「請求額」と「うち交通費（モバイルSuica等）」を分けて入力でき、**交通費は経費計上用に別集計**します
4. **判定**：給与合計が請求合計に足りていても、家庭教師の給与が末日入金のため、**月末より前（26日・27日など）の請求をハンバーグ屋給与＋残高で賄えない場合は「間に合わない」**と判定します
5. **カレンダー表示**：各日付の入金／引き落とし額と、その時点の残高を可視化

### 土日祝の繰り

- **引き落とし**：支払日が土日祝なら **翌営業日** に繰り下げ
- **給与**：給料日が土日祝なら **前営業日** に前倒し
- 日本の祝日（ハッピーマンデー・春分秋分・振替休日・国民の休日）を自動計算

## GitHub Pages で公開する

1. このブランチを GitHub にプッシュ（必要に応じて `main` にマージ）
2. リポジトリの **Settings → Pages**
3. **Source: Deploy from a branch** を選択
4. Branch を公開したいブランチ、フォルダを **`/ (root)`** に設定して保存
5. 数十秒後、表示される URL で公開されます

ビルド不要の素のHTML/CSS/JSなので、追加設定は要りません。

## ファイル構成

- `index.html` … 画面
- `style.css` … スタイル
- `app.js` … 入力・計算・カレンダー描画
- `holidays.js` … 日本の祝日計算

## プライバシー

入力データはあなたのブラウザの `localStorage` にのみ保存され、外部送信は一切ありません。
